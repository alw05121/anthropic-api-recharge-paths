## 先分清：你要充的是哪一个"Anthropic"

Anthropic 名下有三套独立计费体系，余额互不通用。这一点没搞清楚，充完钱才发现用不了的情况非常常见。

| 你在为什么付钱 | 在哪里结算 | 怎么计费 |
| --- | --- | --- |
| Claude API（自己写代码、带 API Key 跑 Claude Code、SDK） | console.anthropic.com → Settings → Billing | 预付费 credits，按 token 扣减 |
| Claude Pro / Max（claude.ai 应用本身） | claude.ai → Settings → Billing | 月订阅，Pro 档 $20/月，Max 有 $100 和 $200 两档 |
| Claude Team / Enterprise | 管理后台或 Anthropic 合同 | 按席位月付，或按 API 费率开发票 |

买 Max 不会给你 API 额度，充了 API credits 也不会让 claude.ai 解锁会员功能。你搜"充值"的时候，得先确定自己是在给哪一张账单付钱。

> 如果你的目标是"让 Claude 能替我写代码"，那你可能根本不需要 API credits——Claude Code 既可以挂在订阅下用，也可以走 API Key 计费，这两条路的花钱方式完全不同。

## 官方充值的流程本身不复杂，复杂的是门槛

流程是公开的，Anthropic 帮助中心写得很清楚：

1. 登录 console.anthropic.com，进 Settings → Billing
2. 点 Add payment method，填入支持国际在线支付的卡，账单地址要和卡上的完全一致
3. 需要合规发票的话填 Business details 和税号（事后可改，但已开出的发票不会重开）
4. 买 credits。首次购买金额可以很小，个位数美元级别就能起步
5. 打开 Auto-reload，设一个阈值，比如余额低于 $50 自动补 $100

第 5 步是整页最有用的开关。生产环境因为余额跑干而中断，是完全可以避免的事故。另外给每个项目或环境建一个 workspace 并设消费上限——这是 Anthropic 目前提供的唯一硬性成本封顶手段。API Key 也建议一个服务一把，不要共用，因为用量报表是按 Key 拆的，共用之后你没法归因。

Credits 是预付制，先买后用；调用失败的请求不计费，只对成功的调用和完成的任务扣钱。余额用尽后 API 和 Workbench 都会直接停掉。还有一点容易忽略：预付费 credits 有有效期，写作时可查到的口径大约是十二个月，所以别一次性囤够一年的量。

## 首次该充多少：看目标，不要看卡

很多人把第一次充值做成了一次大采购，这是最常见的浪费。判断标准其实只有三条：

**只想验证模型适不适合自己。** 小额就够。Tier 1 的公开示例是 $5 首充对应 $100 的月度用量上限。

**两周内就要做高频测试。** 这里有个值得单独考虑的门槛：累计购买达到 $40 会把账户升到 Tier 2，对应月度用量上限提到 $500。如果你知道自己很快会压测，与其先充 $5 再补一次，不如一次到位——Tier 2 带来的是真实的速率和额度变化，不是心理安慰。

**手上已经有云预算或云 credits。** 优先看 Bedrock、Vertex AI 这类托管路径里的 Claude，通常比硬补一条官方直充路线更接近你真实的部署形态。

新注册的 API 账号有时会有小额免费额度（公开整理里常见 $5、30 天有效的说法），但条件通常包括海外手机号、可用的国际卡和合规的访问 IP。是否发放、发多少，以你注册时 Console 里的实际显示为准，别把它写进项目排期。

## 国内开发者到底卡在哪

把"用不了"拆成三件事，就不会绕圈：

## 已知的风险与售后边界

关于第三方订阅，公开反馈里有几个反复出现的点，购买前值得知道：

## 常见问题

**Anthropic API 充值和 Claude Pro 订阅是一回事吗？**

**充了 credits 之后余额能退吗？**

**有免费额度吗？**

**第三方平台能省多少？**
省的不是钱，是流程。官方 $20/月，平台会加上服务费；但如果叠加邀请码优惠和多月套餐的均价折扣，多月的月均成本可能低于单月。真正的省钱来自 Prompt Caching 和 Batch API 这些官方折扣，跟走哪条路无关。
